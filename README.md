# avsync — 独立时钟起始偏差与漂移分析工具

高压开关连续寿命试验后，声响（audio）与触点动作（video）记录来自两台
独立时钟，其对应关系随录像时长逐渐错位。本工具根据记录器导出的时间戳
与同编号同步脉冲，估计独立时钟的**起始偏差 β**与**漂移率 α**，并输出
可追溯的校正时间戳序列。纯 Go 标准库实现，无外部服务与第三方依赖。

## 时钟模型

每段（epoch，对应一次设备重启）内，音频钟读数 `a` 与视频参考钟读数 `v`
满足线性关系：

```
a = α·v + β
```

- `β`：视频零点（v=0）对应的音频读数，单位纳秒，即起始偏差；
- `(α−1)×10⁶`：漂移率，单位 ppm；
- 视频作为参考钟不校正；音频按 `v = (a − β) / α` 校正。
- 保留负时间与可变帧率间隔，**不做任何固定帧率补帧**。

## 处理管线

```
JSONL 解析(input.go) → 计数器解绕(unwrap.go) → 精确时间基换算(timebase.go)
   → 锚点配对与稳健拟合(fit.go) → 校正(correct.go) → JSON/CSV 导出(export.go)
```

- **解绕**：按 (track, epoch) 维护 32/33 位计数器状态；相邻真实增量必须
  严格小于半周期，超过半周期的负跳变判为回绕，其余倒退报错并带行号；
  每个 (track, epoch) 首个解绕 PTS 归零；重启必须显式切换 epoch。
- **时间基**：`math/big` 有理数精确换算，最近偶数（banker's）舍入，
  检测 int64 溢出；JSON 与 CSV 两条导出路径复用同一换算函数，逐项一致。
- **拟合**：以成对斜率中位数（Theil–Sen）初始化，剔除残差超过 2ms 的
  异常锚点，再对内点做最小二乘精化；每段至少 6 对锚点且跨度 ≥60s，
  否则拒绝校正（退出码 3）。
- **内存**：两遍流式处理，常驻内存仅与锚点数/epoch 数成正比；百万条
  记录实测峰值约 14MB，远低于 512MB 约束。
- **原子写**：导出先写同目录临时文件，成功后 rename；任何失败都清理
  临时文件，不留半成品。

## 用法

```bash
# 生成确定性样例（含 25/50fps 交替、计数器回绕、10% 异常锚点）
avsync generate --seed 7 --seconds 7200 --out sample.jsonl

# 分析并双导出；目标时间基默认 1/1e9（纳秒），可用 --tb-num/--tb-den 改
avsync analyze --in sample.jsonl --json fixed.json --csv fixed.csv
```

终端输出（单段）：

```
start_offset_ns=80000002
drift_ppm=240.000
residual_p95_ns=624
corrected_count=988042
```

多段（重启）时逐段打印 `segment/epoch/start_offset_ns/drift_ppm/...`。

### 输入格式（JSONL，每行一条）

| 字段 | 含义 |
|---|---|
| `track` | 仅 `audio` 或 `video` |
| `epoch` | 重启段编号，非负；切换 epoch 表示设备重启 |
| `seq` | 段内序号，非负，同 (track,epoch) 内须严格递增 |
| `pts` | 原始计数器值，非负，32 或 33 位 |
| `num`,`den` | 时间基，1 tick = num/den 秒，均须为正 |
| `bits` | 计数器位宽，32 或 33 |
| `sync_id` | 可选；同编号在两轨同 epoch 内配对，重复即报错 |

### 导出字段

`track, segment(段号), epoch, seq, original_pts, corrected_pts, sync_id`

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 2 | 输入错误（非法字段、重复编号、非法时间基、缺轨、倒退等，均带行号） |
| 3 | 数据不足以可靠拟合（锚点/跨度/内点不足） |
| 4 | 读写失败 |
